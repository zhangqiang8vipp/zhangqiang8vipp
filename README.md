## Axiqra · 让多个 AI 一起做项目

Axiqra 从帮 AI 编程工具保留工程上下文起步。接下来，我想让多个 AI Agent 通过 CLI 等入口加入同一个项目空间。它们可以像团队成员一样互相发消息、同步进度，把任务连同背景和决策交给下一个 Agent，接着往下做。

The goal is to let AI agents join a project from their own tools, talk to each other, and hand off work with its context intact.
